# Digiteka VideoFeed SDK

## Commands

| Command                         | description                                                                                   |
|---------------------------------|-----------------------------------------------------------------------------------------------|
| `./gradlew build`               | generate the `.aar` file in the `sdk/build/output` folder                                     |
| `./gradlew publishToMavenLocal` | publish the sdk as a dependency in your local maven repo. Usefull for testing sdk integration |
| `./gradlew dokkaHtml`           | generate the technical documentation in the `sdk/documentation` folder                        |
