# CLAUDE.md — DTKTester (app de test iOS)

## Contraintes environnement de dev

**Simulateur iOS — raccourcis clavier Mac (Cmd+C / Cmd+V, etc.)** : ne fonctionnent QUE sur un
simulateur exécutant iOS 18 ou supérieur. Sur un simulateur iOS < 18 (ex: iOS 15/17), Cmd+V ne
fait rien et Edit > Paste dans le menu du simulateur reste grisé même avec du contenu dans le
presse-papier — ce n'est pas un bug de l'app, c'est une limitation du simulateur lui-même.

Pour coller du texte (URL de test, mdtk, etc.) dans un champ de DTKTester sur un simulateur
< iOS 18 : basculer sur un simulateur iOS 18+, ou saisir manuellement.
